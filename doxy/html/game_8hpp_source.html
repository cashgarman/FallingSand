15// Declarations shared by the simulation, the window, and the GPU renderer.
16//
17// Ordinary functions and tables are declared here and defined once in game.cpp. That
18// keeps a single external definition for each of them. inline constexpr scalars may be
19// included from several translation units; inline gives those copies one identity.
20//
21// A constexpr function can run at compile time or at runtime. enum class keeps
22// material and scene ids in their own scope. string_view and span borrow text and
23// cells that someone else owns, and they stay valid only while that storage does.
24// array holds the fixed palette without a heap allocation, and class template
25// argument deduction fills in the element type from the initializers.
26// Cell is trivially copyable so its bytes can be copied into a GPU buffer.
27// expected carries success or a reason the UI can show after a save, load, or scene layout.
28// nodiscard marks results the caller needs to look at.
