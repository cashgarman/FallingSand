8// Win32 window owner.
9//
10// The class acquires an HWND and releases it in the destructor. Copying is deleted
11// because two objects would destroy the same window. Declaring the destructor
12// suppresses the implicit move operations, so a Window stays where it was created.
13// handle() and the other observers are const because they do not change that ownership.
14// nodiscard flags results the caller needs. The constructor is explicit so a bool
15// cannot become a Window through an implicit conversion.
