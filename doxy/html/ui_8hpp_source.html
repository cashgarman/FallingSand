11// Immediate-mode layout for the sandbox HUD.
12//
13// Action and Tool are enum classes, so the closed set of commands stays scoped and
14// the compositor can switch on every value. optional is the result of a hit test:
15// either a button or an empty miss, with no error to explain. string_view status
16// borrows text owned by the caller for this frame. array sizes follow the material
17// and scene tables, so a new entry forces the layout arrays to match.
18// Quad is alignas(16) and 32 bytes so the GPU record matches the shader stride.
19// inline constexpr limits are header values with one identity across translation units.

24enum class Action : std::uint8_t
