14// Public GPU facade. Vulkan types stay in vulkan.cpp.
15//
16// Pimpl keeps the public class in this header and the device, swapchain, and
17// pipelines behind unique_ptr<Impl>. unique_ptr is the single owner of that
18// implementation. Copy is deleted so two facades cannot destroy one device.
19// Declaring the destructor also suppresses implicit moves, so the facade stays
20// where it was created.
21// The destructor is declared here and defined in the source file, where Impl is
22// a complete type, because unique_ptr deletes its pointer from the destructor.
23// span and optional on DrawFrame borrow UI quads and a brush stroke for one frame.
24// deviceName() returns a string_view into the device properties owned by Impl.
